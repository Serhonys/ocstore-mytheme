Nordic Form для ocStore 3.0.3.7
================================

Это отдельная тема, собранная как Grand: полный набор шаблонов catalog/view/theme/nordic
и расширение в админке. Свой файл стилей — stylesheet/nordic.css.
Он подключается последним и задаёт холст, шрифты, карточки и чёрные кнопки.
Стили Grand не используются.

Установка
1. Скопируйте содержимое папки upload в корень сайта (туда, где лежит index.php).
2. Админка → Расширения → Расширения → Темы.
3. Nordic Form → Установить → Редактировать.
4. Статус: Включено. Папка шаблона: nordic. Сохранить.
5. Система → Настройки → магазин → вкладка «Магазин» → Тема: Nordic Form. Сохранить.
6. Обновите модификаторы и очистите кэш темы (шестерёнка справа вверху).
