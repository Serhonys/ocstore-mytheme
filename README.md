# mytheme для ocStore 3

Независимая тема: свой CSS, свои Twig, панель в админке. Стили `default` не подключаются.

Витрина собрана по макету NORDIC FORM: холст `#FAFAFA`, линия `#E5E5E5`, чёрная кнопка, моно-цены, карточка товара слева галерея и справа липкая панель. CSS темы `default` не подключается. Цвета, скругление и шрифты меняются в админке и приходят в шапку событием.

## Установка

1. Скопируйте содержимое `upload/` в корень магазина.
2. Дополнения → Дополнения → Шаблоны → Mytheme → Установить → Редактировать.
3. Статус «Включено», сохраните. При установке регистрируется событие `mytheme`.
4. Система → Настройки → магазин → вкладка «Общие» → Тема = Mytheme.
5. Обновите кеш темы.

Размеры фото читает ядро по ключам `theme_mytheme_image_*`. Не переименовывайте их.

## Что свёрстано заново

Шапка, подвал, меню, поиск, корзина, главная, категория, поиск, акции, карточка товара, отзывы, корзина, вход, контакты, статья, 404.

Модули: рекомендуемые, хиты, новинки, акции, категории, фильтр, HTML, слайдшоу, баннер, карусель, кабинет, информация. У всех четырёх товарных модулей одна карточка.

Кабинет кроме входа, шаги оформления заказа и формы оплаты остаются шаблонами `default`. Их классы (`.btn`, `.form-control`, `.table`, `.pagination`, `.alert`) описаны в `stylesheet.css`, поэтому страница не выглядит как голый Bootstrap, но разметка там ещё стандартная.

jQuery, Bootstrap JS и Font Awesome берутся из `catalog/view/javascript/`: их требует `common.js` (корзина, `button('loading')`, `data-dismiss`). CSS Bootstrap не подключается.
